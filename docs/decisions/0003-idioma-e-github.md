# ADR 0003 — Idioma da documentação/artigo e visibilidade do repositório

- **Status:** aceita
- **Data:** 2026-11-07
- **Decisões:** documentação interna e artigo em português; repositório GitHub público.
- **Por quê:** escolha do usuário.
- **Atenção:** repositório público desde o início — não versionar dados sensíveis, e-mails ou PDFs de artigos protegidos por copyright (guardar só fichamentos e links/DOI).
